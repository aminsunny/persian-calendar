# تقویم شمسی شیک برای Apple Calendar ☀️

برای هر روز یک Event تمام‌روزه با عنوانی مثل `☀️ ۱۶ آذر • شنبه` می‌سازد.

## نصب روی آیفون
بعد از قرار دادن این پروژه در GitHub، لینک اشتراک شما این خواهد بود:

`https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/calendar.ics`

در آیفون: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar

یا: Calendar → Calendars → + → Add Subscription Calendar

## آپدیت خودکار
GitHub Actions هر ماه فایل را دوباره می‌سازد و همیشه سال قبل، سال جاری و سال بعد را پوشش می‌دهد. بنابراین لینک Subscription ثابت می‌ماند و لازم نیست هر سال عوضش کنی.
