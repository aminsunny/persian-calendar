# تقویم شمسی برای Apple Calendar

این نسخه برای Apple Calendar ساخته شده و شامل:

- روز هفته به فارسی
- تاریخ شمسی با اعداد فارسی
- مناسبت‌های روزانه ایرانی و جهانی
- تعطیلات رسمی ایران در یک تقویم جداگانه
- به‌روزرسانی خودکار ماهانه
- تولید خودکار سال قبل، سال جاری و سال بعد

## اشتراک‌ها

### تقویم شمسی + مناسبت‌ها
`https://raw.githubusercontent.com/aminsunny/persian-calendar/main/calendar.ics`

### تعطیلات رسمی
`https://raw.githubusercontent.com/aminsunny/persian-calendar/main/holidays.ics`

تقویم تعطیلات را در Apple Calendar روی رنگ صورتی تنظیم کنید.

## منابع داده

برای مناسبت‌های روزانه، ابتدا منبع تقویم Iman Abrisham استفاده می‌شود. اگر سالی در آن منبع موجود نباشد، از دادهٔ Jalali Calendar به‌عنوان fallback استفاده می‌شود. تعطیلات رسمی از مخزن IranHollidaysJSON دریافت می‌شود.
