# تقویم شمسی شیک برای Apple Calendar ☀️

دو اشتراک جدا:
- `calendar.ics`: برای هر روز دو خط جدا: روز هفته + تاریخ شمسی
- `holidays.ics`: تعطیلات رسمی ایران؛ روی آیفون رنگ این Calendar را قرمز بگذار.

لینک‌ها:
`https://raw.githubusercontent.com/aminsunny/persian-calendar/main/calendar.ics`
`https://raw.githubusercontent.com/aminsunny/persian-calendar/main/holidays.ics`

GitHub Actions هر ماه فایل‌ها را برای سال قبل، جاری و بعدی بازسازی می‌کند.
